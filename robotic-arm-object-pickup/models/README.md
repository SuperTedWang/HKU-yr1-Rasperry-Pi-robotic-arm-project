# Model Files

Place the YOLO model folder here:

```text
models/
└─ ENGG1101_YOLO_MODEL_v1/
   └─ my_model.pt
```

The original project mentioned a folder named `ENGG1101_YOLO_MODEL_v1`, but that folder was not present in the current workspace when this repository was prepared.

If the `.pt` file is larger than 100 MB, do not upload it with normal Git. Use Git LFS or attach it to a GitHub Release.
