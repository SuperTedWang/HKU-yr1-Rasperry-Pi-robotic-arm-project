# 发布前检查清单

上传 GitHub 前，建议按开发者视角做一次检查：

- README 是否清楚解释了项目目标、硬件、软件、运行方式和最终结果
- 是否添加了项目演示图片、GIF 或视频链接
- 是否确认所有组员同意公开项目
- 是否决定仓库先设为 Public 还是 Private
- 是否检查过没有私人信息、密码、API key
- 是否确认模型文件大小不超过 GitHub 限制
- 是否把大模型、大视频放到 Git LFS 或 Release
- 是否确认代码能在目标设备上运行
- 是否说明了 YOLO 尝试为什么没有成为最终方案
- 是否说明了最终 OpenCV 方案需要怎样调 HSV 参数
- 是否补充硬件接线图、BOM、机械结构图或照片
- 是否决定采用开源 license，或者暂时不添加 license
